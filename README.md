# TempletePL
Это простой интерпритируемый язык программирования
Чтобы использовать интерпретатор нужно открыть его с первым аргументов путём к файлу или же console для включение ConsoleMode

Команды ConsoleMode:
1. -run запускает введённый код
2. -save <path> сохраняет введённый код в файл
3. -exit выходит из ConsoleMode

Примеры:
1. Переменные:
```
/* Деклорирование Перменных */
let a = 32
var b = 32
str = "Resualt: "
/* Оператор вывода Out */
out str + (a + b)
```
2. Условия:
```
let a = 12
let b = 12
if a == 12 && b != 12
  out "\na == 12 && b != 12"
then elif a != 12 && b == 12
  out "\na != 12 && b == 12"
then else
  out "\na == 12 && b == 12"
end
```
3. Циклы:
```
/* Цикл While */
while true
  out "\nWhile"
  break
end
/* Цикл For */
for let i = 0, i < 10, i++
  our "\nFor: " + i
end
/* Цикл Do While */
do
  out "\nDo While"
then while 1 != 1
```
4. Функции:
```
/* Декларирование Функций */
def sum let a, let b
  return a + b
end
out "Sum: " + sum(10, 10)
/* Пока что существует только 3 внутринии функции*/
clear() /* Очищает Хост Консоль*/
cin()  /* Принимает ввод с клавиатуры (числа и строки)*/
readkey() /* Ожидает нажатие клавиши и возвращает её в виде строчки */
```
